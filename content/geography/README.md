# City directory and editorial release rules

The directory is generated from the [U.S. Census Bureau 2026 National Places Gazetteer](https://www.census.gov/geographies/reference-files/time-series/geo/gazetteer-files.html). Run `python scripts/build-city-inventory.py` with the archived source ZIP in this folder to rebuild `src/cityDirectory.json`. The current 50-state inventory contains 19,702 distinct places: incorporated places plus selected Census-designated communities needed for Hawaii and regions without incorporated places.

Travel-region assignment is a **planning approximation**. The generator assigns each place to the nearest existing representative city using Census coordinates, with the documented Olympia override. These 246 travel regions are not Census administrative boundaries. Review an assignment before publishing a city guide or making a location-specific coverage claim.

Every regional `/cities/` directory is a navigational draft with `noindex`. A city name becomes a linked, prerendered landing page only after `src/cityEditorial.ts` contains a distinct local brief, service answer, seasonal explanation, planning question, public source, and appropriate equipment photo. The five currently reviewed pages are Port Angeles, Sequim, Seattle, Tacoma and Olympia. The other directory entries are deliberately plain text; do not mass-publish copy made only by substituting place names.

The city checker (`npm run check:cities`) verifies unique IDs and paths, one directory per region, only reviewed city links, 250–500-word page bodies, unique photos, and a near-duplicate content threshold. A human editor still needs to review the local claims, service availability wording, image subject, city-to-region assignment and overlap with existing pages before indexing. The site-level domain-routing gate remains closed, so this draft build is `noindex` even for reviewed city pages.

The new kitchen and dishwashing photos were selected from the client's [List of Trailers sheet](https://docs.google.com/spreadsheets/d/1tu6szuEWANuI0gtqrsl9g_gQa0Vm256YD7UmsEtouOc/edit), whose Drive folders hold the original files. The exact Drive file source for each city photo is stored alongside that city's editorial record. The Tacoma sleeper and Olympia combination-unit photos are from the existing Temporary123 media library. Each published city guide uses one image, shown with `object-fit: contain` so the complete equipment image is visible.
